# Участие в разработке

Спасибо, что хотите помочь проекту! 🙌

## Сообщение об ошибке

Создайте issue через [шаблон Bug report](.github/ISSUE_TEMPLATE/bug_report.md).
Опишите шаги воспроизведения и приложите логи.

## Предложение улучшения

Используйте [шаблон Feature request](.github/ISSUE_TEMPLATE/feature_request.md).
Чем конкретнее опишете сценарий использования — тем быстрее получите ответ.

## Pull Request

1. Форкните репозиторий и создайте ветку от `main`.
2. Внесите изменения.
3. Убедитесь, что тесты проходят:
   ```bash
   PYTHONPATH=bin python -m unittest discover -s tests -p "*.py"
   ```
4. Оформите PR по [шаблону](.github/pull_request_template.md).

## Правила

- Код только на чистом Python 3 (стандартная библиотека), без новых зависимостей.
- Изменения логики и конфигурации покрываются unit-тестами.
- Никогда не коммитьте реальные токены Telegram (см. `.gitignore`).
